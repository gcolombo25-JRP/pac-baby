# Pac-Baby 🍼

팩맨 오마주 탑다운 미로 추격 게임. **베이비(플레이어)** 가 미로를 누비며 아이템을 먹고,
**보모(악당)** 를 피해 도망치는 웹 게임입니다.

- Vite 5 + Vanilla JS (ES Modules) + HTML5 Canvas
- 테스트 227개 (`node --test`) · Supabase 클라이언트는 필요할 때만 지연 로딩 (미설정 시 LOCAL 모드)
- 기획/규칙 원본: [`.clinerules`](./.clinerules)

**▶ 휴대폰으로 바로 플레이 (배포 완료)**: <https://gcolombo25-jrp.github.io/pac-baby/>

## 1. 빠른 시작

### Windows (권장)
```
run.bat 더블클릭
```
- Node.js 자동 탐색 → 없으면 안내 후 종료
- 최초 실행 시 의존성 자동 설치
- 브라우저가 **http://localhost:3000** 으로 자동 오픈

### npm
```bash
npm install
npm run dev        # http://localhost:3000
```

서버 종료: 실행 창에서 `Ctrl+C` 또는 `stop.bat`

> Node.js 가 PATH 에 없어도 `run.bat` 은 `C:\Program Files\nodejs` 등 표준 경로를 찾아 실행합니다.
> 터미널에서 직접 npm 을 쓰려면 PATH 에 Node 를 추가하거나 `& 'C:\Program Files\nodejs\npm.cmd' run dev` 를 사용하세요.

## 2. 조작

| 키 | 동작 |
|---|---|
| `← ↑ ↓ →` | 이동 (미리 눌러도 1.2초까지 기억 → 다음 타일에서 자동 적용) |
| 화면 스와이프/드래그 | 모바일에서 캔버스를 끌어 방향 전환 (D-패드와 동시 지원, 24px 이상 이동) |
| `Space` | **울기(비상 탈출)**: 모든 악당 3초 얼림, **-100점**, 얼어 있는 악당은 **+3초 연장**, **쿨다운 3초** (얼린 악당은 무해) |
| 침대(`2`) 타일 진입 | **스텔스 10초** (침대 파란색, 무적, 추격 악당은 5초간 순찰) |
| `P` / `ESC` | 일시정지 토글 (요약 패널 표시) |
| `-` / `+`, `1`~`9`, `0` | 속도 단계 1~10 (기본 1 = 가장 느림) |
| `M` | 음향 + **BGM** on/off |
| `H` / `F1` | **사용 설명서(도움말)** 열기·닫기 (폰은 D-패드의 **도움말** 버튼) |
| `R` | **GAME OVER 에서 재도전** (Space/Enter 도 가능) · STAGE CLEAR 에서 다음 라운드 · **폰은 D-패드의 `재시작` 버튼** |

모바일: 화면 아래 **D-패드**(▲◀▶▼ + 울기/소리/정지/**도움말**/**재시작**)가 자동 표시됩니다.
버튼이 이전보다 **약 33% 커지고**(히트박스는 더 넓게) 손가락이 빗나가도 잘 눌리며,
**캔버스를 스와이프(드래그)**해도 방향을 바꿀 수 있습니다.

### 사용 설명서 (도움말)

- **처음 접속하면 자동으로 한 번** 열립니다(봤는지 여부는 `localStorage` 에 저장).
- PC는 **`H`/`F1`** 키, 폰은 D-패드의 **도움말** 버튼으로 언제든 다시 볼 수 있습니다.
- 목표 · 조작 · **아이템/트랩 표** · 파워업 · **고라운드 난이도** · 울기 · 침대 숨기 · 이기는 팁 · 모바일 안내를 스크롤 한 화면에 정리했습니다.
- 설명서가 열려 있는 동안 게임은 **자동으로 멈추고**(악당·타이머 정지), 닫으면 즉시 이어집니다.
- 자동 표시를 끄려면 URL 뒤에 **`?no-help=1`** 을 붙이세요 (스크린샷/테스트용).

## 3. 게임 규칙

### 점수
| 이벤트 | 점수 |
|---|---|
| 🥛 우유병 섭취 | **+50** |
| 🍬 캔디 섭취 | **+70** |
| 🍪 쿠키 섭취 | **+100** |
| 악당이 트랩을 밟음 | **+100** |
| 보행기 모드로 악당을 날려버림 | **+300** |
| 울기 사용 | **-100** |
| 악당에게 체포 | **-200** |

### 아이템 → 소화 → 트랩
| 아이템 | 소화 시간 | 트랩 | 악당 감속 | 얼림 |
|---|---|---|---|---|
| 우유병 | 5초 | 오줌 | 10% / 10초 | **3초** |
| 캔디 | 7초 | 토사물 | 20% / 10초 | **6초** |
| 쿠키 | 10초 | 똥 | 30% / 10초 | **10초** |

- 아이템은 섭취 후 **15초 뒤 임의 위치에 리스폰** (베이비/악당이 있는 타일 제외)
- 트랩은 바닥에 **20초** 유지, 동시 **최대 6개**, 악당이 밟으면 소모
- 트랩을 밟은 악당은 **종류별로 3/6/10초 얼고**(얼음 동안 무해), **기존 감속(10/20/30%)도 그대로 유지**
- HUD 좌측에 **소화 게이지**(노랑)와 **스텔스 게이지**(파랑)가 고정 슬롯으로 표시됩니다

### 파워업 (특수 메커니즘)
| 파워업 | 발동 | 효과 |
|---|---|---|
| 🍬 **슈가 러시** | 캔디(🍬) 섭취 | **3초** 이동 속도 **+50%**, 몸이 알록달록 깜빡임 |
| 🍼 **황금 젖병** | **맵 정중앙**의 슈퍼 아이템 섭취 | **8초 무적 보행기 모드**: 속도 증가 + 모든 악당이 파랗게 질려 도망 |

- 황금 젖병은 일반 아이템 12개/클리어 카운트에 포함되지 않으며, 먹은 뒤 **20초** 후 맵 중앙에 다시 나타납니다.
- 보행기 모드에서 악당과 부딪히면 **+300점**과 함께 악당이 **스폰 지점으로 날아갑니다** (얼어 있는 악당 포함).
- 보행기 모드가 끝나면 악당은 원래 모드(추격/경비)로 돌아옵니다.
- 두 파워업은 중첩될 수 있으며, 속도 배율은 더 큰 값(×1.5)을 사용합니다.

### 악당
- **추격 2마리(빨강)**: BFS 최단 경로로 추격
- **경비 2마리(주황)**: 베이비와 5타일 이상 떨어진 곳을 순찰 (베이비 타일로는 이동하지 않음)
- **랜덤 스폰**: 28×28 맵을 3×3 구역으로 나눴을 때 **중앙(2행 2열)을 제외한 8개 구역**의 바닥(0)에서 무작위로 등장. 악당끼리 **최소 2칸(맨해튼)** 이상 떨어지며, 4·5라운드 추가 보모도 같은 규칙을 따릅니다.
- 체포 시 베이비는 침대로 귀환하고 1.5초 무적 (악당도 자신의 스폰으로 복귀)
- **속도는 어떤 단계에서도 베이비보다 느림** (1.75배)

### 침대 스텔스
- 침대에 **새로 들어간 순간** 발동 (시작 위치가 침대여도 자동 발동 없음)
- 사용한 침대는 파란색 → 종료 시 원래 빨간색
- 스텔스 중에는 악당과 겹쳐도 잡히지 않음
- 재사용 대기 3초

### 울기 (Space) — 비상 탈출
- 모든 악당을 **3초 얼림**, **-100점**
- **쿨다운 3초** — 3초에 1회만 사용 가능하며, 쿨다운 중 입력은 **비용도 효과도 없음**
- **트랩으로 얼어 있는 악당에게도 사용 가능** — 이때 해당 악당은 **+3초 연장**됩니다 (얼음이 줄어들지 않음)
- 연장 시 색상 보간 기준도 새 기간으로 갱신되어 다시 파란색부터 시작합니다
- **얼어붙은 악당은 무해** — 밟거나 지나가도 체포되지 않음
- **색상**: 막 얼었을 때는 파랑(`#64b5f6`)이고, **남은 시간이 줄수록 원래 색**(추격 빨강 / 경비 주황)으로 서서히 돌아옵니다
- 얼음이 풀린 뒤 같은 타일에 있으면 다시 위험하므로 그 전에 벗어나야 함

### 화질 · 비주얼
- **레티나 고해상도(DPR)**: `devicePixelRatio`(최대 3배)에 맞춰 캔버스 내부 해상도를 키우고 논리 좌표(640×640)로 그립니다 → 텍스트·라인이 선명하며, 창 크기/모니터가 바뀌면 자동 재적용
- **네온 아케이드 미로**: 벽 테두리에 푸른 네온 글로우(`shadowBlur`) + 벽 모서리 하이라이트/그림자, 바닥 체크 패턴
- **베이비 조명**: 반경 약 3.6타일의 원형 조명 + 주변부 비네트로 입체감 (정적 맵은 오프스크린 캐시에 1회만 그려 성능 유지)
- **캐릭터 생동감**: 이동 시 통통 튀는 바운스·스쿼시, 진행 방향을 따라 움직이는 눈동자와 깜빡임, 얼음/감속 상태 표시
- **아이템/트랩**: 더 크고 세밀해진 아이템 접시 + 회전 반짝이, 흔들리는 트랩 웅덩이 (오줌 노랑 / 토사물 연두 / 똥 갈색)

### 시각 효과 (Juice)
- **아이템 섭취**: 노란 반짝이 파티클
- **트랩 배출**: 트랩 색 물방울이 퐁 튀는 파티클
- **울기 발동**: 화면 전체 푸른 섬광 + 퍼져 나가는 충격파 링 + 눈물/얼음 파편
- **파워업**: 슈가 러시 = 무지개로 깜빡이는 몸 + 색색 반짝이, 황금 젖병 = 황금 링/왕관 별 + 금빛 조명 + 악당 식은땀/파란 얼굴
- **체포**: **0.2초 카메라 셰이크** + 붉은 피격 섬광 (월드만 흔들리고 HUD 는 고정)
- 모두 **Canvas 코드**로만 그립니다 (외부 이미지 파일 없음)

### 배경 음악 (BGM)
- Web Audio 오실레이터로 만든 **8비트 루프** (멜로디 + 4분음표 베이스)
- 첫 키 입력/클릭에서 시작하며 **`M` 키로 음향과 함께 on/off**
- 일시정지 중에는 BGM 도 멈춥니다

### 목숨 · 게임 오버
- 목숨 **3개**(하트)로 시작, 체포될 때마다 **1개 차감** (`-200점`은 그대로 적용)
- 목숨 **0 → GAME OVER** 오버레이: 최종 점수 · HI-SCORE · `NEW RECORD!` · **`[R] 재도전`** (폰은 **재시작** 버튼)
- 재도전 시 점수 0 · 목숨 3 · 라운드 1로 초기화 (하이스코어는 유지)

### 라운드 클리어 · 하이스코어
- **아이템 12개를 모두 섭취하면 STAGE CLEAR** (`constants.ROUND_CLEAR_MODE` 로 `SCORE`/`BOTH` 전환 가능)
- 클리어 보상: **목숨 +1**(최대 3), 다음 라운드는 **`Space`/`Enter`로 진입**(자동 진행 없음)
- 다음 라운드: 점수·목숨·하이스코어 유지 / 아이템·트랩·소화·스텔스 초기화 / **속도 단계 +1(최대 10)**
- **HI-SCORE**는 `localStorage`(`pacbaby.hiscore`)에 저장되어 새로고침 후에도 유지, HUD에 `HI:` 로 표시
- 하이스코어 초기화: **`?reset-hi=1`** (예: `http://localhost:3000/?reset-hi=1`)

### 고라운드 난이도
- **4라운드**: 추격 보모 **+1** (총 5마리) · **5라운드**: 순찰 보모 **+1** (총 6마리)
- **6라운드**: 철창문 1개 등장. **2라운드마다 +1** (8→2, 10→3, 12→4, 최대 4개)
  - 열림 3초 ↔ 닫힘 3초 반복. 닫히면 베이비·보모 **모두 통과 불가**.
  - 문 위에 캐릭터가 있으면 닫히지 않고 기다립니다.
- **8라운드**: 시야 제한 시작. 시야 반경 **8타일 → 라운드마다 -1 → 최소 3타일**
  - 벽/미로 구조/보모는 어둠에 가려지고, **아이템과 트랩은 반짝이며 보입니다**.
  - 철창문은 어둠 속에서도 작은 상태등(초록=열림 / 빨강=닫힘)으로 표시됩니다.

### 자동 일시정지
- 브라우저 탭을 벗어나거나 창을 최소화하면 **자동으로 PAUSED**
- 돌아와도 자동 재개되지 않음 → `P` 또는 `ESC`로 재개

### 글로벌 리더보드 · 게스트 선행 플레이
- 첫 방문에는 **닉네임 입력 없이 바로 플레이**합니다(Supabase Anonymous Auth).
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` 가 없으면 **LOCAL 모드**로 동작하며 기록은 브라우저에만 저장됩니다.
- 게임 오버 시 **접속 3회 / 최고 500점 / 2라운드** 중 하나를 만족하면 닉네임+이모지 등록 모달이 부드럽게 표시됩니다.
  - **[나중에]** 를 고르면 다음 3번의 게임 오버 동안 다시 묻지 않습니다. (강제 가입 없음)
- 등록하면 같은 uid 의 기존 게스트 기록이 그대로 **글로벌 리더보드(Top 50, 30초 캐시)** 에 반영됩니다.
- 리더보드/등록은 캔버스 좌상단 **프로필 배지** 또는 도움말의 **🏆 리더보드** 버튼으로 엽니다.
- **보안**: `users`/`runs` 테이블 직접 수정은 RLS+GRANT 로 차단되고, 점수는 서버 run 토큰·최소 플레이 시간·라운드별 상한·1회성 검증을 통과해야만 `greatest()` 로 갱신됩니다.
  - DEMO/BOT/테스터 치트로 플레이한 런은 제출되지 않습니다.
- Supabase 프로젝트/마이그레이션 설정: **[`supabase/README.md`](./supabase/README.md)**

## 4. 테스터 모드 (개발/QA용)

여는 방법 (둘 중 하나)
- **`F2`** 키
- URL 뒤에 **`?test=1`** → `http://localhost:3000/?test=1` (모바일 권장)

### 모드 스위치 (하나만 활성, `F3` 순환)
| 버튼 | 의미 |
|---|---|
| **1 MANUAL** | 직접 플레이 + 치트 |
| **2 REPLAY** | 기록한 입력 재생 (끝나면 MANUAL 복귀) |
| **3 BOT** | AI 자동 플레이 (얼린 악당 무시 · 도망 불가 시에만 자동 울기 · 황금 젖병은 낮은 우선순위) |

### 기능 스위치 (독립, `localStorage` 에 저장)
| 스위치 | 효과 |
|---|---|
| 무적 | 악당과 겹쳐도 체포되지 않음 |
| 무벽 | 벽 통과 (베이비만) |
| 악당 정지 | 모든 악당 고정 |
| 1틱 모드 | 게임을 멈추고 `F4`/`⏭ 1틱`으로 한 틱씩 진행 |
| 상태 라벨 | 캔버스 좌상단에 TEST 상태/좌표/점수 표시 |

### 모바일 도움말 모달 · 자동 데모 플레이

- 모바일 플레이 화면의 봇 버튼은 제거했습니다. **D-패드의 [? 도움말]** 버튼으로 연 모달에서 아래 액션을 실행합니다.
  - **[▶ 게임 시작]**: 닫고 READY/PLAYING으로 시작·재개 (게임 오버/클리어에서는 새 게임/다음 라운드)
  - **[🤖 데모 실행]**: 닫고 봇 데모 플레이를 즉시 시작
  - **[■ 게임 종료]**: 닫고 일시정지 (P/ESC로 재개)
- PC의 개발자용 봇은 기존처럼 `F2` → BOT에서 사용합니다.
- 시작 후 **5초 동안 키/터치 입력이 없으면** 자동으로 **DEMO PLAY**가 시작됩니다.
- 데모 중 키를 누르거나 화면을 터치하면 **즉시 MANUAL**로 복귀합니다.
- 봇 판단:
  - 얼어붙은 악당은 위협에서 제외하고 얼어붙은 타일은 안전하게 통과합니다.
  - **울기**는 1~2타일 내 위협이 있고 **실제로 도망칠 길이 없을 때만** 사용합니다.
  - **황금 젖병**은 주변 아이템이 없거나 충분히 가까울 때만 추격해 과도한 집착을 줄였습니다.
  - 황금 젖병 보행기 모드에서는 가장 가까운 악당에게 돌진합니다.

## 7. 배포 (무료)

- Pac-Baby 는 **정적 사이트**라서 **GitHub Pages / Vercel / Netlify** 무료 배포가 가능합니다.
  글로벌 리더보드는 **선택적으로 Supabase** 를 사용하며, 미설정 시 LOCAL 모드로 동작합니다.

- `vite.config.js` 의 **`base: './'`** 덕분에 GitHub Pages 의 하위 경로(`/pac-baby/`)에서도 에셋이 정상 로드됩니다.
- **업로드**: `push.bat` 더블클릭 (최초 1회 GitHub 로그인) → **Settings → Pages → Source: GitHub Actions**
- **GitHub Pages 자동 배포**: `.github/workflows/deploy.yml`
  - `main`/`master` push → `npm ci` → `npm test` → `npm run build` → Pages 업로드/배포
  - 최초 1회 저장소 **Settings → Pages → Source: GitHub Actions** 설정 필요
- **Vercel**: 저장소 Import → Framework `Vite` → Build `npm run build` → Output `dist`
- 자세한 절차·공유 방법·체크리스트·문제 해결: **[`DEPLOY.md`](./DEPLOY.md)**

### 카카오톡 인앱 브라우저 캐시 대응
- `vite.config.js` 가 **모든 JS/CSS/청크에 콘텐츠 해시**(`assets/index-<hash>.js`)를 붙이고,
  `assetsInlineLimit: 0` 으로 항상 별도 파일로 방출합니다 → 배포마다 파일 이름이 바뀌어 캐시가 자동 무효화됩니다.
- 빌드 시 **`dist/version.json`** 이 생성되고, `index.html` 의 인라인 스크립트가 이를 `cache: 'no-store'` 로 확인합니다.
  이전에 본 빌드와 다르면 `?v=<빌드ID>` 를 붙여 **자동 새로고침**하므로 카카오톡 웹뷰의 강한 HTML 캐시도 우회합니다.
- `dist/index.html` 에는 `Cache-Control: no-store` 메타 태그도 포함됩니다.
- 배포는 `.github/workflows/deploy.yml` 이 `main` push 시 자동 수행합니다.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| `node`/`npm` 명령을 찾을 수 없음 | `run.bat` 사용 (자동 탐색) 또는 PATH 에 `C:\Program Files\nodejs` 추가 |
| `npm.ps1` 실행 정책 오류 | `npm.cmd` 사용 (run.bat 이 이미 그렇게 동작) |
| 포트 3000 사용 중 오류 | `stop.bat` 실행 (다른 포트는 `stop.bat 3100`) 또는 `run.bat --port 3100` |
| 소리가 안 남 | 첫 키 입력/클릭 이후 활성화됨 · `M` 으로 음향 확인 · 브라우저 탭 음소거 확인 |
| 수정한 코드가 반영되지 않음 | **`Ctrl+Shift+R`** 강력 새로고침 (이전 탭/서버 캐시) |
| 게임이 멈춘 것 같음 | 콘솔(F12) `[Pac-Baby] loop error` 메시지 확인 (루프는 보호되어 계속 실행됨) |
| 하이스코어를 지우고 싶음 | `?reset-hi=1` 로 접속 (예: `localhost:3000/?reset-hi=1`) |
| 게임 오버 후 다시 시작 | `R`(또는 Space/Enter) — 점수 0 · 목숨 3으로 재시작 |
